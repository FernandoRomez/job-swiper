    🧠 Claude por MCP (sin API key)

    JobSwiper le pasa cada petición a tu editor (Claude Code / Antigravity) a través del servidor MCP jobswiper. No se usa ninguna API key y todo ocurre en tu equipo. Arranca el servidor MCP en esta carpeta y, cuando la app necesite IA, pídele en el chat: «atiende las tareas de JobSwiper».

    Comprobando puente MCP…

    🔑 API Key de Google Gemini

    Consíguela gratis en aistudio.google.com/apikey. Se guarda en tu equipo (config.json) y las llamadas salen desde el servidor local, no desde el navegador. También puedes definir GOOGLE_API_KEY como variable de entorno.
